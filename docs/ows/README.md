## Что доступно по нашему токену

Все 18 корневых GraphQL-запросов проверены живыми вызовами 2026-07-27 —
доступ есть везде, отдельных прав не требуется:

`Subjects` (участники) · `TrdBuy`/`ObTrdBuy` (объявления) · `Lots`/`ObLots`
(лоты) · `Contract`/`ObContract` (договоры) · `Acts` (электронные акты) ·
`Plans`/`ObPlans` (годовые планы) · `TrdApp` (заявки поставщиков) ·
`Rnu` (недобросовестные) · `qualifiedSuppliers` · `ComplaintAppeal`
(апелляции) · `News` · `ContractWaybill*` (накладные).

Префикс `Ob*` — модуль «Конкурс и аукцион» (system_id=2), основные корни —
текущая версия ГЗ (system_id=3).

## Что мы используем сейчас

`api/queries.py` — три запроса:

- `LISTING_QUERY` — `Lots` (17 полей) для листинга;
- `DETAIL_QUERY` — `TrdBuy` + вложенные `Lots` + `Files`;
- `CONTRACTS_QUERY` — `Contract` (10 полей из 101) + `ContractUnits`.

Плюс REST `/v3/refs/ref_contract_status` через `api/refs.py`.

## Особенности фильтров (проверено вживую)

- `Lots.plnPointKatoList` — фильтр **есть**, но принимает КАТО **строкой и
  только целиком** (`"751110000"`); префикс `"75"` даёт пусто. Поэтому регион
  по-прежнему фильтруем клиентски по префиксу.
- `Lots.enstruList` — тип `[Int]`, но в выдаче поле почти всегда `[0]`;
  как фильтр бесполезно. Код ЕНС ТРУ берётся из `Plans[].RefEnstru.code`.
- Текстовые поля поддерживают спецсимволы: `{nameRu: "?программн"}` —
  подстрока без морфологии, `{nameRu: "*уголь"}` — с морфологией,
  без символов — точное совпадение. Работает на сервере, проверено.
- Даты — массивом: `{crdate: ["2019-10-01", "2019-10-24"]}` = «с … по»,
  `{crdate: ["", "2019-10-24"]}` = «по».

# Recon: что снять на живом конкурсе (чтобы я доделал робота)

Цель — собрать данные, которые видны только на реальном проходе подачи. По ним я
заполню места `TODO(recon)` в `wizard.py` / `tumar.py`. Снимать на узле, где
стоят NCALayer + Tumar (**с 2026-07-28 это macOS**, см. гайд §6.3), будучи
**залогиненным** на v3bl.goszakup.gov.kz.

> Команды ниже даны для Windows. На macOS всё то же самое, кроме частей C и D:
> `recon_dump` использует `pywinauto` и там не работает. Дерево окна Tumar на
> маке снимается штатным **Accessibility Inspector** (входит в Xcode: Xcode →
> Open Developer Tool → Accessibility Inspector; навести на поле цены и кнопки,
> прислать скриншот панели со свойствами). Ожидаемые контролы известны из
> символов плагина: `priceInput`, `okButton`, `cancelButton` и действие
> `cryptButtonClicked`. Аналогично для окна NCALayer.

## Часть A. HAR с телами ответов (Chrome/Edge)

Прошлые HAR были без тел ответов — в этот раз нужны именно **с телами**.

1. Открой страницу конкурса, нажми **F12** → вкладка **Network (Сеть)**.
2. Включи галку **Preserve log (Сохранять журнал)** — чтобы записи не сбрасывались
   при переходах визарда.
3. Пройди весь визард подачи (лоты → документы → цена → preview), можно без
   финального клика «Подать».
4. Правый клик в списке запросов → **«Save all as HAR with content»**
   (именно *with content* — это включает тела ответов).
5. Сохрани файл, отдай мне.

## Часть B. Селекторы визарда — через Playwright codegen (рекомендую)

Codegen открывает браузер и сам пишет селекторы по мере твоих кликов.

```powershell
.venv\Scripts\python -m playwright codegen https://v3bl.goszakup.gov.kz
```

1. В открывшемся окне **войди по ЭЦП** (NCALayer сработает как обычно).
2. Дойди до конкурса и **кликай по шагам визарда**: «Подать заявку», галочки
   лотов, «Далее», прикрепление документа, «Далее», кнопку запечатывания цены,
   preview. В окошке **Playwright Inspector** будет копиться код с селекторами.
3. Скопируй весь сгенерированный код (из Inspector) и отдай мне — там будут
   готовые локаторы для каждой кнопки.

(Если codegen не пойдёт — запасной вариант: на каждой кнопке правый клик →
**Inspect** → запиши её `id`, `name` или видимый текст.)

## Часть C. Окно ввода цены Tumar — утилитой recon_dump

Когда на шаге цены **открылось нативное окно Tumar** (туда вводят цену), НЕ
закрывая его, открой второе окно PowerShell и запусти:

```powershell
# 1) список всех окон — найди строку с окном Tumar
.venv\Scripts\python -m agent.recon_dump
# 2) дамп его контролов (подставь часть заголовка из шага 1)
.venv\Scripts\python -m agent.recon_dump "Tumar"
```

Отдай мне весь вывод второй команды (там TITLE + список контролов с `auto_id`).
По нему я заполню `GZ_TUMAR_WINDOW_TITLE` и поля в `tumar.py`.

## Часть D. Окно NCALayer (выбор ключа / PIN)

Так же, в момент входа, когда NCALayer показал окно выбора ключа или ввода PIN:

```powershell
.venv\Scripts\python -m agent.recon_dump            # найди заголовок окна NCALayer
.venv\Scripts\python -m agent.recon_dump "NCALayer" # дамп контролов
```

Вывод — мне. По нему автоматизирую логин в `wizard._login`.

## Часть E. reCAPTCHA

На шаге **preview / финальной подачи** посмотри: появляется ли «Я не робот»
(галка/картинки)? Если да — отметь, на каком шаге. Если подача проходит без неё —
тоже отметь. (По прошлому разбору капчи на самой подаче не было — подтверждаем.)

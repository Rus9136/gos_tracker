Как это работает
  1. Скрейпит листинг goszakup с фильтрами filter[customer], filter[trade_type], filter[year], filter[status][], filter[amount_from/to].
  2. Идёт по каждому году отдельно (на сайте фильтр годовой), всё пишется в один прогон.
  3. По новым / сменившим статус лотам дополнительно тянет детальную карточку: organizer, договоры, контакты.
  4. Документы и LLM пропускает — это отдельный шаг.
  5. Закрытые лоты, которые уже есть в БД, повторно не пересканируются.
